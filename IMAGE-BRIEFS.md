# Gramvista image collection

These are generated illustrative photographs, not photographs of actual Gramvista staff, premises, customers or completed projects. All ten final images are stored in this repository as compressed WebP assets; there are no runtime external image dependencies.

## Shared direction

Premium corporate commercial photography; realistic modern African business context; natural light; clean neutral surfaces; restrained navy and blue details. No logos, watermarks, holograms, cyberpunk treatment or text overlays. Interfaces use abstract layouts without claims about live systems.

## Product concept

Product cards now use typographic identities and capability lists rather than conceptual application screenshots. The legacy SmsPreview component is unused; only verified product screenshots should replace the current identities.

## Replacements

Replace each WebP file individually with approved imagery. Service paths and alt text are in `src/data/services.ts`. The hero and company photos are referenced by their corresponding components. Retain the original fallback SVG until another local fallback is supplied. Do not use these generated photos as evidence of completed work. Real portfolio records and galleries must use approved project materials.

Each WebP is roughly 80–135 KB. The hero also has a JPEG social-preview version for crawler compatibility. The original PNGs were preserved in the generation output directory; the website does not depend on those originals. A source manifest is retained under `scripts/photo-sources.json` for provenance.
